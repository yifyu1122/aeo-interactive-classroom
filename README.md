## 五大教學單元架構

### 單元 1：認識 AEO 生態系統 (Ecosystem Intuition)
- **概念圖解**：介紹自然界生態系統中三大角色如何轉換為演算法的搜尋機制：
  - **🌿 生產者 (Producer)**：由適應值最差的個體擔任，吸收外部隨機能量，負責大步進行全域探索（Exploration），跳出局部陷阱。
  - **🦅 消費者 (Consumer)**：個體相互追蹤（草食/肉食/雜食），朝其他個體的位置差前進，平衡開採與探索（Exploitation + Search）。
  - **🍄 分解者 (Decomposer)**：全體圍繞目前最佳解進行高斯擾動，執行精細區域搜尋（Local Refinement）。
- **探索問題**：引導思考為何最差個體適合擔任生產者、為何純依賴互相靠近會導致早熟收斂。附點擊展開之詳細參考答案。

### 單元 2：生產階段 Production (Interactive Explorer)
- **核心提問**：「如果目前已經找到一個不錯的位置，還需要探索其他地方嗎？」
- **互動實驗**：
  - 手動拖動權重係數 $a$（$0 \sim 1$）與迭代進度 $t/T$。
  - 即時動態觀察新生產者 $x'_1 = (1-a)x_n + a \cdot x_{rand}$ 在「最佳解 $x_n$」與「隨機探索點 $x_{rand}$」連線上的拔河。
  - 視覺化長條圖即時展示權重分割，清晰呈現公式中 $a = (1 - t/T)r_1$ 隨進度縮小搜尋範圍之道理。
- **探索問題**：探討 $a \to 0$ 與 $a \to 1$ 時的極限位置與退化行為。

### 單元 3：消費階段 Consumption (核心教學)
- 拆為四個可獨立操作切換之子單元：
  1. **🌿 草食者 (Herbivore)**：式 (6) $x' = x_i + C(x_i - x_1)$，參考生產者 $x_1$。
     - 醒目提醒：**不能說「草食者往生產者移動」**！當消費係數 $C < 0$ 時方向反轉朝生產者走；當 $C > 0$ 時方向向外反衝探索！
  2. **🦅 肉食者 (Carnivore)**：式 (7) $x' = x_i + C(x_i - x_j)$，參考排在自己前面的同伴 $x_j$ ($2 \le j < i$)。
     - 詳解索引條件限制：為什麼排名第 2 的消費者只能當草食者？
  3. **🐾 雜食者 (Omnivore)**：式 (8) $x' = x_i + C [r_2(x_i - x_1) + (1-r_2)(x_i - x_j)]$。
     - 三步驟分解展示：(1) 與生產者差值；(2) 與同伴差值；(3) 依 $r_2$ 權重混合後的綜合位移。
  4. **⚖ 三種食性直接比較 (Comparison)**：固定相同起點、生產者、同伴與係數 $C$，並排展示三種食性的運動向量差異！
- **探索問題**：包含負消費係數的運動方向、食性退化分析與雜食者非平均點的幾何本質。

### 單元 4：分解階段 Decomposition (Refinement)
- **核心提問**：「為什麼第一階段的最佳解還需要被擾動？新解一定會變好嗎？」
- **公式與擾動**：展示式 (9)～(12) $x' = x_{best} + D(e \cdot x_{best} - h \cdot x_i)$。
- **貪婪選擇機制 (Greedy Selection)**：計算新舊目標函數值 $f(x')$ vs $f(x_i)$，動態呈現「✓ 接受更新」或「✗ 拒絕更新（保留原位置）」。
- **探索問題**：探討高斯擾動的隨機性、貪婪法維持單調不劣的必要性、以及越界後的合法重抽處理。

### 單元 5：完整 AEO 搜尋實驗室 (Full Algorithm Lab & Pseudocode)
- **AEO 虛擬碼同步高亮 (Pseudocode Synchronization)**：
  - 單步執行時，右側虛擬碼清單即時高亮當前程式碼行（如初始化、排序、生產、消費、分解、貪婪接受判斷）。
- **搜尋空間展示**：
  - 1D 模式：函數曲線、候選解圓點、位移箭頭、最佳/最差標籤。
  - 2D 模式：等高線/熱圖、二維平面軌跡。
- **播放控制器**：開始、暫停、下一步、上一步、重設、時間軸跳轉、速度切換。
- **候選解觀測表**：各個體 ID、坐標、目標值、當前狀態與本輪食性分布統計。
- **收斂曲線與多次實驗對照**：保存不同參數設定重跑，疊加收斂曲線，支援匯出 UTF-8 CSV。

## 數學模型與原始論文對照

本教材嚴格依據 Zhao, Wang & Zhang (2020) 原文第 2.2 節實作：

| 階段 | 原文公式 | 意義與說明 |
|---|---|---|
| **生產 Production** | 式 (1)–(3) | $x'_1 = (1-a)x_n + a \cdot x_{rand}$，其中 $a = (1-t/T)r_1$。在最佳解與界內隨機點間加權。 |
| **消費係數** | 式 (4)–(5) | $C = \frac{1}{2}\frac{v_1}{\|v_2\|}$，$v_1, v_2 \sim \mathcal{N}(0, 1)$。正負號決定前進或反轉。 |
| **草食 Herbivore** | 式 (6) | $x' = x_i + C(x_i - x_1)$。以生產者為參考對象。 |
| **肉食 Carnivore** | 式 (7) | $x' = x_i + C(x_i - x_j)$，$j \in [2, i-1]$。以排序在自己前面的消費者為參考。 |
| **雜食 Omnivore** | 式 (8) | $x' = x_i + C[r_2(x_i - x_1) + (1-r_2)(x_i - x_j)]$。兩組差值的隨機權重組合。 |
| **分解 Decomposition** | 式 (9)–(12) | $x' = x_{best} + D(e \cdot x_{best} - h \cdot x_i)$，$D = 3u, e = r_3 k - 1, h = 2r_3 - 1$。以最佳解為基準擾動。 |
| **貪婪選擇** | 第 2.2.3 節 | 僅當 $f(x') < f(x_{old})$ 時才接受移動；若越界則在 $[L, U]$ 內重新均勻抽樣一次。 |

> **論文勘誤備註**：原文正文第 2.2 節中，式 (7) 參考單一消費者對應肉食，式 (8) 混合生產者與消費者對應雜食；但原文圖 6 的英文標籤兩者文字顛倒。本教材依正文的數學定義為準。

## 程式架構與單元測試

- **`engine.js`**：AEO 純數學演算法核心，無 DOM 依賴，狀態可回溯。
- **`units.js`**：單元 1～4 的獨立互動展示、動態 SVG 繪圖器與事件監聽。
- **`app.js`**：單元 5 實驗室控制器、虛擬碼行高亮同步、收斂圖、CSV 匯出。
- **`plot.js`**：搜尋空間繪圖（1D 曲線、2D 熱圖、位移向量箭頭、收斂圖）。
- **`lesson.js`**：詳細步驟算式與抽樣精度解說面板。
- **`style.css`** & **`lesson.css`**：臺大 GeoComput Lab 風格之學術雙欄佈局、精緻卡片與 details 探索問題樣式。

在 Node.js 環境中驗證數值正確性：
```bash
node tests.cjs
```
包含生產公式、三種消費公式、分解公式、固定種子可重現性、邊界處理、回溯狀態一致性等 10 項嚴格單元測試，全部 100% 通過。
