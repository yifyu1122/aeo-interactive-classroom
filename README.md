# AEO 人工生態系統最佳化互動教材

[開啟線上教材](https://yifyu1122.github.io/aeo-interactive-classroom/) · [GitHub 原始碼](https://github.com/yifyu1122/aeo-interactive-classroom)

這是以繁體中文編寫的 AEO（Artificial Ecosystem-based Optimization，人工生態系統最佳化）互動教材。它用生態系統中的生產、消費與分解，帶出候選解如何更新；也提供公式、逐步播放與實際計算紀錄，方便初學者學習及檢查演算法。

教材以最小化目標函數為例。生態比喻用來幫助理解搜尋流程，不代表數學上的最優性證明；AEO 是啟發式方法，不保證每次都找到全域最佳解。

## 快速開始

本專案使用原生 HTML、CSS 與 JavaScript，沒有後端或建置步驟，也不需安裝套件。

1. 下載或複製此專案。
2. 用桌面瀏覽器開啟 `index.html`。
3. 可在「演算法實驗室」調整函數與參數，重新執行並逐步檢視事件。

執行程式測試需安裝 Node.js，然後在專案資料夾執行：

```sh
node tests.cjs
```

## 五個教學單元

1. **前言：生態系統與最佳化** — 認識生產者、消費者、分解者，以及探索與利用；用地形尋找低點建立最佳化直覺。
2. **生產：探索新位置** — 看隨機位置如何與目前最佳位置組合，並理解權重 `a` 如何隨迭代進度變化。
3. **消費：三種搜尋策略** — 分別介紹草食、肉食、雜食，展示位置差、消費係數與參考個體。
4. **分解：以最佳解為基準擾動** — 逐項說明 `D`、`e`、`h`，以及越界處理和新舊解比較。
5. **演算法實驗室** — 以一維或二維圖表觀察候選解、逐步播放、查看族群與收斂紀錄、比較執行結果並匯出 CSV。虛擬碼預設為簡易說明，可切換完整中文版本；點選程式行可查看對應事件的公式、參考對象、隨機數與實際計算。顯示內容取自演算法事件紀錄，沒有為了動畫補造不存在的食性更新。

## AEO 更新公式

以下公式以個體位置向量 `x` 表示；`f(x)` 越小越好。公式編號依 Zhao 等人的論文。

| 階段 | 公式 | 說明 |
| --- | --- | --- |
| 生產 | (1) `x₁(t+1) = (1-a)xₙ(t) + a x_rand` | 最差個體以最佳個體與隨機位置的加權組合產生候選解。 |
| 生產 | (2) `a = (1 - t/T)r₁` | `r₁ ∈ [0,1]`；隨迭代進行，`a` 的可能上限縮小。 |
| 生產 | (3) `x_rand = L + r(U-L)` | 每一維各取 `r ∈ [0,1]`，在上下界間抽樣。 |
| 消費係數 | (4) `C = 0.5 v₁ / |v₂|` | `v₁`、`v₂` 為標準常態亂數；`v₂` 不為零。係數可正可負。 |
| 消費係數 | (5) `v₁, v₂ ~ N(0,1)` | 以標準常態分布產生消費係數所需亂數。 |
| 草食 | (6) `xᵢ' = xᵢ + C(xᵢ - x₁)` | 使用自己與本輪生產者的位置差。 |
| 肉食 | (7) `xᵢ' = xᵢ + C(xᵢ - xⱼ)` | 參考排序索引 `2 ≤ j < i` 的消費者。 |
| 雜食 | (8) `xᵢ' = xᵢ + C[r₂(xᵢ-x₁)+(1-r₂)(xᵢ-xⱼ)]` | 對兩個位置差加權，不是直接平均兩個參考位置。 |
| 分解 | (9) `D = 3u` | `u ~ N(0,1)`。 |
| 分解 | (10) `e = r₃k - 1` | `r₃ ∈ [0,1]`，`k ∈ {1,2}`。 |
| 分解 | (11) `h = 2r₃ - 1` | 與 `e` 共用 `r₃`。 |
| 分解 | (12) `xᵢ' = x_best + D(e x_best - h xᵢ)` | 以目前最佳位置為基準產生候選解。 |

引擎對每個候選解執行邊界檢查；若任一維越界，會重新抽取整個位置向量一次，再計算目標值。只有 `f(新解) < f(舊解)` 時才接受更新。這是本程式對論文未明確交代的越界重抽次數所採用的實作約定。

### 食性公式標籤說明

原論文正文第 2.2 節將式 (7) 用於肉食、式 (8) 用於雜食；圖 6 的英文標籤在這兩式上有對應差異。本教材依正文公式與文字說明實作，並在程式中保留註記。

## 論文工程案例

第六單元提供 §4.1–4.8 八項案例閱讀器，包含題意、變數、目標、限制概念、AEO 建模方式及圖表來源。三桿桁架附單點應力與目標評估器。此功能未將八題接入原 AEO 播放引擎，也未重跑論文結果。

軸承案例依附錄採最大化動態承載力，並揭露 §4.7 正文 minimized 與附錄 Maximize 的差異。複雜工程限制仍應以原文附錄核對，不能將摘要當作完整求解模型。

### 工程實物與模型對照

第五單元為演算法實驗室；第六單元獨立呈現八種案例的圖像閱讀器。各案例包含本機參考照片或結構示意圖、原創 SVG 論文模型、尺寸標記及外部資料來源。參考物件不代表論文作者製作的原型；兩者差異直接寫在圖說。

圖像署名與授權存於 `assets/engineering/credits.json`，頁面也可展開查看。圖片依原授權使用；原創 SVG 不替代工程施工圖。圖片載入不依賴外部網站。新增內容未修改 `engine.js` 的數學邏輯。

### 單元六尺寸互動

八種案例採左側 SVG 模型、右側尺寸滑桿與計算回饋，實物參考圖改為可展開查看。每個案例可還原尺寸，切換案例會保留該案例目前的滑桿值。改動尺寸只影響示意模型，不修改參考照片，也不啟動 AEO。

桁架提供目標與三項應力檢查，懸臂梁提供目標與撓度檢查；彈簧、壓力容器、焊接梁只計算頁面明列的目標或容量。離合器顯示體積與質量關係，沒有指定密度就不顯示質量。齒輪只展示幾何，軸承提供 Dₘ、Dᵦ、Z 三個幾何控制及鄰球間距檢查，尚未涵蓋完整十變數承載力模型。所有圖形均為正規化教學示意，不能用作工程驗證。

執行 `node engineering-tests.cjs` 驗證各控制的圖形更新、已實作的數值與狀態；既有引擎測試仍為 `node tests.cjs`。
