UNIT 01 / ECOSYSTEM INTUITION

以自然界生態循環，啟發電腦搜尋最佳解

在真實大自然中，能量從太陽傳遞給植物（生產者），再被各類動物（消費者）攝取，最後殘留物經由細菌真菌（分解者）回歸大地。 Zhao、Wang 與 Zhang（2020）提出的 AEO 演算法，便將數值最佳化問題的「候選解」對應到這三種角色，透過角色的動態更替，巧妙兼顧演算法的「探索（Exploration）」與「利用（Exploitation）」。

🌿 生產者 (Producer)

吸收外部能量。在演算法中，由目前適應值最差的個體擔任。它在目前最佳解與搜尋空間內隨機位置之間取凸組合，藉此進行全域探索，避免陷入死胡同。

任務：宏觀探索（Exploration），把表現最差的個體拉到新區域重新嘗試。

🦅 消費者 (Consumer)

動物個體之間互相學習、追蹤或捕食。分為草食者、肉食者、雜食者三種不同食性策略，隨機選取，參考生產者或其他更優秀的同伴，以位置差進行跳躍。

任務：局部開採與族群互動（Exploitation + Search），向潛在更佳區域靠攏。

🍄 分解者 (Decomposer)

將各個體與當前全球最佳解的差異進行隨機高斯擾動。此階段以最佳解為基準出發，微調搜尋已知最優區域的細部結構。

任務：細緻微調（Local Refinement），以貪婪法則評估並保留較佳位置。

核心挑戰：為什麼需要兼顧「探索」與「利用」？

最佳化演算法在複雜地貌中尋找谷底時，面臨兩難困境：

探索 (Exploration)

跳出舒適圈，往未知的遠處隨機搜尋。優點是有機會發現隱藏在深處的全域最優；缺點是如果探索過度，會像無頭蒼蠅一樣難以收斂。

利用 (Exploitation)

在目前已知最好的點附近進行地毯式細緻微調。優點是能精準找出谷底最低點；缺點是如果過早鎖定，就容易陷入局部陷阱無法自拔。

探索問題 · 思考與判讀

先根據生態常識與直覺猜猜看，再點擊展開閱讀演算法設計背後的道理。

  1. 為什麼 AEO 要讓「目前適應值最差的個體」去擔任生產者，而不是讓最好的個體去？

    先猜猜看 ▾ 查看參考答案
    如果讓最好的個體去進行劇烈的隨機探索，可能會失去辛苦找到的好位置；相反地，把目前全族群表現最差的個體（生產者）拿來做大幅度隨機躍遷，即便探索失敗也不可惜，成功了還能開闢全新搜尋方向，是極高效率的汰弱機制！

  2. 如果一個演算法只有「消費者互相靠近」的規則，容易發生什麼不良後果？

    先猜猜看 ▾ 查看參考答案
    若所有個體都只朝著彼此或目前看似不錯的點聚攏，很快整個族群就會失去多樣性，縮成一團卡在某個「局部極小值（Local Minimum）」中動彈不得，這在演算法中稱為「早熟收斂（Premature Convergence）」。這正是為什麼 AEO 還需要生產者與分解者的隨機擾動機制。

  3. 三種角色在每一次演算法迭代中，執行的先後順序是如何安排的？

    先猜猜看 ▾ 查看參考答案
    每一輪迭代開始時，先將全體依目標值從最差排到最好。接著依序進行：① 最差者執行「生產」；② 其它消費者依序執行「消費」（草食、肉食或雜食）；③ 記錄第一階段結束後的最佳解；④ 全體個體依該最佳解執行「分解」。最後更新全域紀錄，進入下一代。

UNIT 02 / PRODUCTION EXPLORER

生產 Production：最佳解與隨機位置的拔河

核心問題：「如果目前已經找到一個不錯的位置，還需要探索其他地方嗎？」
在生產階段，新生產者的候選位置是由「目前最佳解」與「界內隨機產生的位置」進行線性加權產生。透過控制權重係數 a，演算法能在「繼承既有經驗」與「探索嶄新天地」之間取得動態平衡。

白話解說： 新生產者位置必定落在「最佳解」與「界內隨機點」的連線上。當 a 很大時，受隨機點牽引多，屬於大膽探索；當 a 很小時，緊貼最佳解，屬於保守開採。

探索問題 · 思考與判讀

動手拖動滑桿，再驗證你的預測。

  1. 當 a 調到極端值 0 或 1 時，新生產者分別會落在哪裡？

    先猜猜看 ▾ 查看參考答案
    當 a = 0 時，式子變成 x'₁ = xₙ，新生產者完全重疊在目前最佳解上；當 a = 1 時，式子變成 x'₁ = x_rand，完全變成一個界內隨機點。真實的 a 介於 0 與 1 之間，因此新解是兩點的凸組合（Convex Combination）。

  2. 為什麼公式要設計 a = (1 - t/T) × r₁，讓權重上限隨著迭代輪數增加而逐漸縮小？

    先猜猜看 ▾ 查看參考答案
    在演算法搜尋前期（t 很小），族群尚未找到優良區域，因此 (1 - t/T) 接近 1，允許較大的 a 往外隨機大步探索；隨著搜尋到了後期（t 接近 T），(1 - t/T) 趨近於 0，強制 a 變小，使新生產者主要貼近目前最佳解進行細緻收斂，完美實現「先廣域探索、後精準開採」的原則。

  3. 如果算出的新位置 x'₁ 目標函數值比原先最差的點還要差，演算法會接受它嗎？

    先猜猜看 ▾ 查看參考答案
    不會！AEO 採取嚴格的貪婪選擇規則（Greedy Selection）：只有當 f(x'₁) < f(x₁)（新位置得到更佳目標值）時，才會接受更新；若新位置較差或相等，則保留原本的位置，確保演算法族群不會倒退。

UNIT 03 / CONSUMPTION & DIET STRATEGIES

消費 Consumption：草食、肉食、雜食三種移動策略

這是 AEO 最具特色的核心機制。排名在第 2 到第 n 名的個體都是消費者。 消費者會隨機採取三種食性之一來更新位置。請點選下方切換子單元，手動調整係數，直觀比較三種食性的運動特徵。

草食者規則：草食者只吃植物（生產者）。它計算自己與生產者的位置差，乘上消費係數 C 來決定下一步去哪裡。

肉食者規則：肉食者捕捉其他消費者。它只能挑選排名在自己前面的消費者 x_j (2 ≤ j < i) 作為參考對象，以此位置差進行跳躍。

雜食者規則：雜食者葷素不拘。它同時計算與生產者的位置差、與另一位消費者的位置差，以隨機權重 r₂ 加權混合後乘上 C 跳躍。

三種食性直接比較：在相同起點個體、相同生產者、相同同伴與相同消費係數 C 條件下，觀察三種不同食性策略產生的位移向量差異。

探索問題 · 思考與判讀

動手調整係數 C 與 r₂，再驗證你的觀察。

  1. 如果消費係數 C 是負數（例如 C = -0.5），草食者會朝哪個方向移動？可以直接說「草食者往生產者移動」嗎？

    先猜猜看 ▾ 查看參考答案
    不可以直接說草食者往生產者移動！因為公式是 x' = xᵢ + C(xᵢ - x₁)。位置差是 (自己 - 生產者)，如果 C > 0，個體反而會沿著遠離生產者的方向向外探索；只有當 C < 0（例如 -0.5）時，負號反轉了方向，個體才會朝向生產者靠近（例如走到兩點的中間）。

  2. 為什麼肉食者不能任意挑選參考對象，而必須符合 2 ≤ j < i 的規則？排名第 2 的消費者為什麼不能當肉食者？

    先猜猜看 ▾ 查看參考答案
    因為 AEO 的排序規則是由最差排到最好（x₁ 最差，xₙ 最好）。條件 j < i 確保了肉食者只能參考排在自己前面的其他消費者。而排名第 2 的個體 i = 2 前面只有第 1 名的生產者，不存在其他消費者（2 ≤ j < 2 無解），所以在完整 AEO 中第 2 名個體強制執行草食策略。

  3. 雜食者的權重 r₂ 如果接近 1，或是接近 0，分別會退化成什麼食性？

    先猜猜看 ▾ 查看參考答案
    當 r₂ = 1 時，雜食者完全只參考生產者的位置差，行為完全等同於草食者；當 r₂ = 0 時，雜食者完全只參考另一位消費者的位置差，行為完全等同於肉食者。因此雜食者是兩者的平滑過渡加權！

  4. 雜食者的新位置是「生產者與同伴位置的直接平均」嗎？

    先猜猜看 ▾ 查看參考答案
    不是！雜食者混合的是「兩組位置差」：r₂(xᵢ - x₁) + (1 - r₂)(xᵢ - xⱼ)，混合之後還要乘以隨機消費係數 C，最後再加上自己原本的位置 xᵢ。它代表的是複合的引導方向，並非簡單的點坐標平均。

UNIT 04 / DECOMPOSITION REFINEMENT

分解 Decomposition：圍繞全域最佳解的微調擾動

核心問題：「為什麼第一階段結束後的最佳解還需要被擾動？新解一定會變好嗎？」
在分解階段，全體個體不再以彼此為參考，而是通通改以「第一階段結束時產生的最佳解 x_best」為基準出發，根據自身與最佳解的差異施加高斯隨機擾動。

原論文公式 · 式 (9)～(12)

D = 3u  (u 取自標準常態)
e = r₃ × k − 1  (k 取 1 或 2)
h = 2 × r₃ − 1
x' = x_best + D × (e × x_best − h × xᵢ)
• 基準最佳解 x_best = 0.10
• 目前個體位置 xᵢ = 2.80
• 計算擾動位移 = -1.28
• 候選新解 x' = x_best + 擾動位移 ≈ -1.18

白話解說： 分解階段以全族群目前已知最棒的點 x_best 作為錨點出發。擾動量大小由常態分佈亂數 D 控制，方向則取決於括號內的加權組合。最後透過貪婪法則嚴格檢驗，確保只有變得更優的解才能被保留。

探索問題 · 思考與判讀

觀察擾動結果，再閱讀參考答案。

  1. 為什麼分解階段不保證新位置一定比舊位置更好？

    先猜猜看 ▾ 查看參考答案
    因為分解係數 D = 3u 是從標準常態分佈隨機抽取的，有時候擾動過大會直接跳出好的區域，甚至跳到分數很差的高處。因此提出新位置只是「大膽嘗試」，必須搭配「嚴格評估」：只有 f(新) < f(舊) 才會接受，否則個體保留原位。

  2. 分解階段和前一階段（消費階段）最大的不同是什麼？

    先猜猜看 ▾ 查看參考答案
    消費階段的起點是「個體自己原本的位置 xᵢ」，朝著生產者或同伴的方向跳躍；而分解階段的起點直接切換成「目前全球最佳解 x_best」，等於全族群的所有個體都把目光轉向最成功的代表，在它周圍鋪開一張擾動搜尋網！

  3. 如果分解階段計算出的新位置超出了搜尋範圍邊界 [L, U]，演算法會如何處理？

    先猜猜看 ▾ 查看參考答案
    根據論文第 2.2.3 節規範，當任一維度越界時，演算法會在上下界範圍 [L, U] 內重新均勻隨機抽取一個合法位置，再進行目標函數評估，確保所有候選解始終落在合法定義域內。

  1. 先在範圍內抽出一群位置，算出各自的目標值。
  2. 依目標值排序，找出最差個體與目前最佳個體。

  6. 分解者以本輪最佳位置為基準提出擾動候選解。
  7. 記錄歷史最佳；到達迭代上限後回傳結果。

      先猜猜看 ▾ 查看參考答案
      因為在每一次消費階段，草食者與雜食者都在參考生產者；肉食者在參考比自己好的同伴；而在分解階段，全體個體更是以全球最佳解 x_best 為基準擾動。貪婪選擇會持續保留在低窪處的優秀點，導致整個族群的位置分佈迅速向最有潛力的谷底凝聚。

    2. 切換到「二維 Rastrigin 函數」跑跑看。為什麼完整 AEO 有時會卡在某個小山谷，而無法每次都找到 (0,0) 的絕對谷底？

      先猜猜看 ▾ 查看參考答案
      Rastrigin 函數具有密密麻麻的局部極小值（Local Minima）。這類啟發式演算法本質上屬於隨機近似最佳化，並非數學上的穷舉法，無法在有限迭代次數內保證 100% 找到全域最佳解。若要提升跳出率，通常可以增大族群大小 n 或多次獨立執行。

    3. 當族群大小 n 從 8 增加到 20 時，每一輪迭代花費的「函數評估次數（Function Evaluations）」會如何變化？

      先猜猜看 ▾ 查看參考答案
      初始化階段評估 n 次；每輪生產評估 1 次，消費評估 n - 1 次，分解評估 n 次。因此每一輪合計新增 2n 次評估！總評估次數為 n + 2nT。當 n 增加時，搜尋空間取樣更廣泛，但每輪的計算成本也成正比上升。

    操作指南與學習路徑

    1. 單元 1 建立直覺：先了解生態系統中三大角色的分工，理解為什麼最佳化演算法既需要大膽的「探索」也需要細緻的「開採」。
    2. 單元 2 動手調權重：拖動生產權重 a，觀察新生產者如何受到最佳解與隨機探索點的拉扯，理解為何權重上限隨時間縮小。
    3. 單元 3 比較三種食性：草食者參考生產者、肉食者參考同伴、雜食者混合兩者。特別注意消費係數 C 為負時朝參考點前進，為正時反方向探索。
    4. 單元 4 觀察分解擾動：圍繞當前最佳解擾動，並觀察「貪婪法則」如何篩選新解，只接受變得更好的提案。
    5. 單元 5 完整演算法實驗：按「下一步」逐步執行，對照右側高亮的虛擬碼，觀察多個候選點在 1D 或 2D 搜尋空間的收斂過程！
    6. 單元 6 工程設計案例：對照八種工程案例的實物與結構圖，辨認尺寸變數，再看目標與限制。三桿桁架提供指定設計的計算器。
